### PROMPT TEMPLATE FOR AI ###

Напиши MIDI-данные в формате JSON для следующего запроса: 
[ВСТАВЬ СВОЙ ЗАПРОС ТУТ, НАПРИМЕР: Арпеджио Am 16-ми нотами]

Используй строго эту структуру:
{
  "bpm": 120,
  "notes": [
    {"p": 60, "t": 0.0, "d": 0.25, "v": 80},
    {"p": 64, "t": 0.25, "d": 0.25, "v": 85}
  ]
}

Параметры:
p (pitch) — номер MIDI ноты (60 = C4).
t (time) — время начала (в долях).
d (duration) — длительность (1.0 = четверть, 0.25 = 16-я).
v (velocity) — сила нажатия (0-127).

Выдай ТОЛЬКО чистый JSON без комментариев.
