# MidiGen 🎹

MidiGen — это легкий локальный инструмент для музыкантов и продюсеров, который превращает текстовые JSON-данные в полноценные MIDI-файлы. 

Проект создан для автоматизации рутинного прописывания нот в DAW (например, REAPER), позволяя генерировать сложные партии, арпеджио и аккорды через описание в ИИ.

### Основные возможности:
- **JSON to MIDI**: Быстрая конвертация структурированного списка нот.
- **Humanization**: Автоматическое добавление легкой вариативности к Velocity и Timing для "живого" звучания.
- **Offline First**: Не требует API-ключей, работает полностью локально.

### Как использовать:
1. Попроси ИИ (например, ChatGPT) создать музыкальную партию в формате JSON (шаблон промпта ниже).

Шаблон промта
```
Напиши MIDI-данные в формате JSON для следующего запроса: [ТВОЙ ЗАПРОС].
Используй строго эту структуру:
{
"bpm": 120,
"notes": [
{"p": 60, "t": 0.0, "d": 1.0, "v": 80},
{"p": 62, "t": 1.0, "d": 1.0, "v": 85}
]
}
Где: p = pitch (нота), t = time (старт), d = duration (длительность), v = velocity.
Выдай только чистый JSON без лишних слов.
```

2. Скопируй JSON и вставь его в поле ввода MidiGen.
3. Нажми "Generate" и забери готовый `output.mid` в свой проект в DAW.

### Системные требования:
- Python 3.8+
- Библиотеки: `midiutil`, `customtkinter` (или `streamlit`)
